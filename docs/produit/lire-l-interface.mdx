L'interface Sairen suit des conventions constantes : les connaître permet de lire n'importe quel écran d'un coup d'œil.

## Les boutons

| Couleur | Signification |
| --- | --- |
| **Violet** | L'action principale de l'écran |
| **Jaune orangé vif** | **Enregistrer** |
| **Rouge** | Action destructive (suppression, blocage) — à confirmer |

## Les fonds et repères

- **Fond jaune** = une note (voir [les notes de la fiche contact](/produit/contacts#notes)).
- **Puce colorée dans un en-tête de colonne** = la couleur du groupe d'origine (voir [les puces de couleur](/produit/labels-groupes-colonnes#puces-de-couleur)).

## Les badges d'état des agents

Chaque agent porte un **badge d'état unique** :

- **Brouillon** — en cours de conception, inactif ;
- **Actif** — en service ;
- **Inactif** — arrêté, sans être supprimé.

Voir [Comprendre les agents Rainbow](/produit/rainbow-agents) pour le cycle de vie complet.
