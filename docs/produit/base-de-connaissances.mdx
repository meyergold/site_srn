<p class="srn-eyebrow">Produit</p>

La Base de connaissances rassemble ce que vos agents IA ont le droit de savoir : c'est leur unique source de vérité.

<span id="sources" />

## Les sources de données

Trois types de sources alimentent la Base de connaissances :

- **Documents** : fichiers importés (procédures, catalogues, FAQ internes…).
- **Site web** : pages aspirées depuis une URL.
- **Questions/réponses** : paires rédigées directement dans la plateforme.

<span id="dossiers" />

## Organiser en dossiers

Les sources se rangent en dossiers, dont les noms sont libres. Bonnes pratiques :

- un thème = un dossier ;
- **évitez les doublons de dossiers** du type « Docs » / « documents » — la plateforme vous avertira ;
- préférez des noms explicites (« Procédures accueil » plutôt que « Divers »).

<span id="indexation" />

## L'indexation

Après ajout ou modification d'une source, la plateforme **indexe** le contenu : c'est cette étape qui le rend utilisable par vos agents IA. Une source non indexée n'est pas encore visible des agents.

## Questions fréquentes
