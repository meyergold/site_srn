Un agent Sairen est un assistant IA que vous configurez pour traiter des conversations selon vos règles. Il s'appuie sur la [Base de connaissances](/produit/base-de-connaissances) et n'invente rien.

<span id="etats-agent" />

## Les états d'un agent

Chaque agent porte un **badge d'état unique** :

- **Brouillon** — en cours de conception, il ne traite rien.
- **Actif** — en service, il traite selon ses règles.
- **Inactif** — arrêté sans être supprimé ; réactivable à tout moment.

La marche à suivre détaillée (rôle, connaissances, données à collecter, voix, réglages d'appel) est décrite dans [Paramétrer votre agent IA](/who_and_what).
