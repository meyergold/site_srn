<p class="srn-eyebrow">Produit</p>

Labels, groupes et colonnes forment le moteur central d'organisation de Sairen : ils structurent Desk, Océan et Contacts. Comprendre ce mécanisme une fois vous évite de le redécouvrir écran par écran.

<span id="labels" />

## Les labels

Un label est une étiquette créée **par type** et attachée aux objets de la plateforme (conversations, tâches, contacts…).

1. Créez un label pour le type d'objet concerné.
2. Attachez-le manuellement — ou laissez un déclencheur IA le faire (voir plus bas).

Le nom d'un label est **libre** : casse, orthographe et vocabulaire vous appartiennent.

<span id="groupes" />

## Les groupes

Un groupe rassemble des labels qui vont ensemble. Chaque groupe :

- porte une **couleur**, que vous retrouvez partout où le groupe apparaît ;
- peut porter un **déclencheur IA** (voir section suivante) ;
- a un nom **libre**, défini par vous.

<span id="declencheur-ia" />

## Le déclencheur IA

Quand un groupe porte un déclencheur IA, l'IA classe automatiquement les objets entrants : elle attache le bon label du groupe sans intervention manuelle. Vous gardez la main — un label posé par l'IA se retire ou se remplace comme n'importe quel label.

<span id="colonnes-dynamiques" />

## Les colonnes dynamiques

Les colonnes des tableaux (Desk, Océan, Contacts) ne sont pas figées : elles sont **générées dynamiquement à partir de vos groupes et de vos filtres**. Créer un groupe, c'est créer la colonne qui va avec ; les noms de colonnes sont, eux aussi, libres.

<span id="puces-de-couleur" />

## Les puces de couleur

La puce colorée dans un en-tête de colonne indique **la couleur du groupe d'origine** de cette colonne. C'est le fil conducteur visuel entre vos groupes et vos tableaux.

## Questions fréquentes

<AccordionGroup>
  <Accordion title="Puis-je imposer une convention de nommage à mon équipe ?">
    Sairen n'impose rien : noms de labels, groupes et colonnes sont libres. Si votre organisation veut une convention, c'est une règle interne à vous — la plateforme acceptera toutes les variantes.
  </Accordion>

  <Accordion title="Que se passe-t-il si je change la couleur d'un groupe ?">
    La puce des colonnes issues de ce groupe reprend immédiatement la nouvelle couleur, partout.
  </Accordion>
</AccordionGroup>
