Rainbow est le studio d'automatisation de Sairen : vous y composez des **workflows** qui exécutent vos règles métier sur les conversations, les tâches et les contacts.

## Le concept de workflow

Un workflow est un enchaînement d'actions déclenché par un événement (un nouveau message, un label posé, un rendez-vous créé…). Il agit sur le reste de la plateforme : envoyer un message, créer une tâche dans Desk, lancer un appel vocal IA, mettre à jour un contact.

Rainbow combine deux logiques :

- **Déterministe** quand il faut être sûr (des règles qui s'exécutent toujours pareil) ;
- **Intelligent** quand il faut de la souplesse (un agent IA décide).

Voir [Rainbow : agents](/produit/rainbow-agents) pour la partie agents IA.
