<p class="srn-eyebrow">Labels & classification</p>

Un groupe de labels ne sert à rien s'il reste invisible : affichez-le en colonne pour voir, ligne par ligne, comment vos échanges sont classés.

## Le principe

Un groupe de labels = une colonne. Cette colonne est disponible dans les trois tableaux du produit : **Contacts**, **Desk** et **Océan**. Chaque ligne y affiche les labels du groupe posés sur l'élément — par vous ou par la classification automatique.

## Ajouter la colonne

<Steps>
  <Step title="Ouvrez « Gérer les colonnes »">
    Depuis le tableau concerné (Contacts, Desk ou Océan), ouvrez le menu **Gérer les colonnes**.

    <Frame caption="Le menu « Gérer les colonnes » d'un tableau.">
      <img src="/images/labels/groupes-et-colonnes-1.png" alt="Menu Gérer les colonnes" />
    </Frame>
  </Step>

  <Step title="Ajoutez une colonne personnalisée">
    Cliquez sur **Ajouter une colonne personnalisée**.
  </Step>

  <Step title="Choisissez un ou plusieurs groupes">
    Sélectionnez le groupe à afficher. Vous pouvez en combiner plusieurs dans la même colonne — par exemple « Statut Réservation + Priorité ».

    <Frame caption="Sélection des groupes de labels pour la colonne.">
      <img src="/images/labels/groupes-et-colonnes-2.png" alt="Choix des groupes pour une colonne personnalisée" />
    </Frame>
  </Step>

  <Step title="Réordonnez">
    Glissez la colonne à la position voulue dans le tableau.
  </Step>
</Steps>

<Info>
  Une colonne peut combiner **plusieurs groupes**. En revanche, seuls les labels de type **tâche** s'affichent dans une colonne personnalisée.
</Info>

<Tip>
  Utilisez **Appliquer ces colonnes à toute l'organisation** pour que toute votre équipe voie le même tableau, sans que chacun refasse le réglage.
</Tip>
