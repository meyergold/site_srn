<p class="srn-eyebrow">Labels & classification</p>

Vos appels, messages et e-mails arrivent en continu : les groupes de labels les rangent automatiquement, pour que vous retrouviez chaque échange au bon endroit.

## Label, groupe, type : les trois notions

Un **label** est une étiquette posée sur un élément : « SCANNER EPAULE », « Prise de rendez-vous », « Urgent ». Chaque label a un **type**, qui indique sur quoi il se pose : une **conversation**, une **tâche**, un **contact** ou un **appel**.

Un **groupe de labels** rassemble des labels cohérents entre eux. Par exemple, le groupe « Priorité » contient Basse, Normale, Haute et Urgent. C'est le groupe que vous créez, modifiez et affichez — pas les labels un par un.

Chaque groupe porte deux textes distincts :

- une **description**, écrite pour vos collègues, qui explique à quoi sert le groupe ;
- une **consigne de classification**, écrite pour l'IA, qui lui dit comment choisir le bon label. Voir [La classification automatique](/labels/classification).

## Pourquoi des groupes ?

Les groupes servent à trois choses :

- **Organiser** : des labels cohérents restent ensemble, avec une couleur commune.
- **Classer** : l'IA lit chaque échange et pose le bon label du groupe, sans intervention manuelle.
- **Afficher** : un groupe devient une colonne dans vos tableaux Contacts, Desk et Océan.

## Le cycle complet

Tout suit le même enchaînement, en trois temps :

1. **Définir** : vous créez le groupe, ses labels et sa consigne de classification.
2. **Classifier** : un workflow Rainbow contenant l'étape « Classifier une tâche » applique la consigne à chaque échange — appel, message ou e-mail.
3. **Afficher** : le groupe apparaît en colonne dans vos tableaux, et chaque ligne montre ses labels.
