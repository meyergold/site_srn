**Administration** est l'unique endroit où se gère votre organisation : c'est là que se créent et se modifient les entités, les membres et les équipes.

<Info>
  **Prérequis** : le rôle **Administrateur** (voir [Comprendre les rôles](/compte/roles#roles)).
</Info>

## Le modèle d'organisation

Votre organisation cliente se structure ainsi : **organisation → entités et/ou équipes → membres avec rôles**. Les noms d'entités et d'équipes sont libres.

<span id="entites" />

## Gérer les entités

Une entité représente un établissement : l'**établissement principal**, et si besoin des **établissements secondaires**.

1. Ouvrez Administration.
2. Créez l'entité (ou modifiez une entité existante).
3. Rattachez-y les membres et équipes concernés.

<span id="membres" />

## Gérer les membres

Un membre est un utilisateur de votre organisation, porteur d'un rôle (Membre ou Administrateur).

1. Ouvrez Administration.
2. Invitez le membre (adresse e-mail professionnelle, ex. `exemple@clinique-dupont.fr`).
3. Attribuez son rôle et rattachez-le à ses entités / équipes.

<span id="equipes" />

## Gérer les équipes

Une équipe regroupe des membres qui travaillent ensemble (par métier, par site, comme vous voulez — le nom est libre).

1. Ouvrez Administration.
2. Créez l'équipe et ajoutez ses membres.

<span id="mon-compte-vs-administration" />

## « Mon compte » vs Administration

- **Mon compte** ne concerne que votre profil personnel : informations et mot de passe.
- **Administration** gère tout le reste : entités, membres, équipes.

Si vous cherchez où créer un utilisateur ou un établissement : c'est toujours Administration.
