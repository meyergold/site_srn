<p class="srn-eyebrow">Compte</p>

Sairen distingue trois rôles. Le rôle détermine ce qu'un utilisateur peut voir et gérer — il se définit dans **Administration**, au niveau de chaque membre.

<span id="roles" />

## Les trois rôles

| Capacité | Membre | Administrateur | Sairen Admin |
| --- | --- | --- | --- |
| Traiter conversations et tâches (Océan, Desk) | ✅ | ✅ | ✅ |
| Gérer les contacts | ✅ | ✅ | ✅ |
| Créer / modifier entités, membres, équipes (Administration) | ❌ | ✅ | ✅ |
| Ajouter des canaux et connexions IA & données | ❌ | ✅ | ✅ |
| Connecter un MCP externe | ❌ | ✅ | ✅ |
| Intervenir en support sur l'espace | ❌ | ❌ | ✅ |

- **Membre** : l'usage quotidien — traiter, collaborer, consulter.
- **Administrateur** : la configuration de l'organisation — entités, membres, équipes, canaux.

<span id="sairen-admin" />

## Sairen Admin

**Sairen Admin** est le rôle réservé au support Sairen : il permet à nos équipes d'intervenir sur votre espace pour vous accompagner (paramétrage, diagnostic). Ce rôle n'est pas attribuable à vos utilisateurs.
