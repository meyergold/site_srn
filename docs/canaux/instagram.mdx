<p class="srn-eyebrow">Canaux</p>

Branchez un compte **Instagram professionnel** pour recevoir vos **messages privés (DM)** dans [Océan](/produit/ocean), aux côtés de vos autres canaux. Une fois connecté, place à l'usage : [Instagram dans Océan](/produit/instagram).

<Info>
  **Prérequis**

  - Rôle **Administrateur** (voir [Comprendre les rôles](/compte/roles#roles)).
  - Un compte Instagram **professionnel** (Business ou Créateur), relié à une **Page Facebook** / un compte **Meta Business**.
  - Les droits pour **autoriser l'accès aux messages** du compte.
</Info>

<Steps>
  <Step title="Connecter Instagram">
    <div style={{position: 'relative', width: '100%', aspectRatio: '16 / 9', margin: '8px 0'}}>
      <iframe src="https://www.youtube.com/embed/Xjm8SbcbSU8" loading="lazy" title="Connecter Instagram à Sairen" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen frameBorder="0" style={{position: 'absolute', top: '0', left: '0', width: '100%', height: '100%', borderRadius: '16px', border: '1px solid rgba(120, 110, 255, 0.25)'}} />
    </div>

    Depuis **Intégrations**, choisissez **Instagram** et connectez le compte via **Meta Business** : authentifiez-vous et **autorisez Sairen** à accéder aux messages du compte professionnel. La connexion suit le [parcours d'ajout unifié](/canaux/ajouter-un-canal).
  </Step>

  <Step title="Vérifier dans Océan">
    Envoyez-vous un **DM de test** : il doit apparaître comme conversation dans [Océan](/produit/ocean#conversations). Vous pouvez maintenant échanger — voir [Instagram dans Océan](/produit/instagram).
  </Step>
</Steps>

## Erreurs fréquentes

<AccordionGroup>
  <Accordion title="Mon compte Instagram n'est pas détecté">
    Le compte doit être **professionnel** (Business ou Créateur) et relié à une **Page Facebook** / un compte **Meta Business**. Un compte personnel ne peut pas être branché.
  </Accordion>

  <Accordion title="Les messages n'arrivent pas dans Océan">
    Vérifiez que l'**accès aux messages** est autorisé côté Instagram et que la connexion est active. Un premier message peut prendre quelques instants à remonter.
  </Accordion>

  <Accordion title="Un autre réseau ou canal ?">
    Voir le parcours unifié : [Ajouter un canal](/canaux/ajouter-un-canal). Pour WhatsApp, voir [Brancher WhatsApp](/canaux/whatsapp).
  </Accordion>
</AccordionGroup>
