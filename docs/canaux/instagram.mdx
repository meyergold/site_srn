<p class="srn-eyebrow">Canaux</p>

Branchez un compte **Instagram professionnel** pour recevoir et traiter vos **messages privés (DM)** dans [Océan](/produit/ocean), aux côtés de vos autres canaux — puis répondez à vos abonnés sans quitter Sairen.

<Info>
  **Prérequis**

  - Rôle **Administrateur** (voir [Comprendre les rôles](/compte/roles#roles)).
  - Un compte Instagram **professionnel** (Business ou Créateur), relié à une **Page Facebook** / un compte **Meta Business**.
  - Les droits pour **autoriser l'accès aux messages** du compte.
</Info>

<Steps>
  <Step title="Connecter Instagram">
    <div style={{position: 'relative', width: '100%', aspectRatio: '16 / 9', margin: '8px 0'}}>
      <iframe src="https://www.youtube.com/embed/Xjm8SbcbSU8" loading="lazy" title="Connecter Instagram à Sairen" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen frameBorder="0" style={{position: 'absolute', top: '0', left: '0', width: '100%', height: '100%', borderRadius: '16px', border: '1px solid rgba(120, 110, 255, 0.25)'}} />
    </div>

    Depuis **Intégrations**, choisissez **Instagram** et connectez le compte via **Meta Business** : authentifiez-vous et **autorisez Sairen** à accéder aux messages du compte professionnel. Envoyez-vous ensuite un **DM de test** : il doit apparaître comme conversation dans [Océan](/produit/ocean#conversations).
  </Step>

  <Step title="Aller sur Océan">
    <Frame>
      ![Ouvrir Océan depuis le menu de gauche](/images/motion/ocean-aller-sur-ocean.png)
    </Frame>

    Depuis le menu de gauche, ouvrez **Océan** : vos **DM Instagram** — et vos autres canaux — arrivent dans cette inbox unifiée, chaque conversation qualifiée automatiquement.
  </Step>

  <Step title="Répondre aux messages Instagram">
    <div style={{position: 'relative', width: '100%', aspectRatio: '16 / 9', margin: '8px 0'}}>
      <iframe src="https://www.youtube.com/embed/TlgHuxok_PY" loading="lazy" title="Gérer le canal Instagram depuis Océan" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen frameBorder="0" style={{position: 'absolute', top: '0', left: '0', width: '100%', height: '100%', borderRadius: '16px', border: '1px solid rgba(120, 110, 255, 0.25)'}} />
    </div>

    Ouvrez une conversation pour **lire, répondre et assigner** — votre réponse repart vers Instagram, sans quitter Océan.
  </Step>

  <Step title="Labéliser les conversations">
    <Frame>
      ![Labéliser une conversation dans Océan](/images/motion/ocean-labeliser.gif)
    </Frame>

    Appliquez des **labels** pour trier et prioriser (ex. _À traiter_, _Prospect_, _SAV_) — ils alimentent les filtres et les analyses IA.
  </Step>

  <Step title="Laisser Ulysse gérer mes DM">
    [Ulysse](/produit/ulysse), le copilote IA de Sairen, peut traiter vos messages Instagram en **langage naturel** — trier, résumer, répondre, créer des tâches. Connectez-le d'abord avec une clé API :

    <Card title="Connecter Ulysse avec une clé API" icon="key" href="/produit/ulysse#connecter-cle-api">
      La vidéo de mise en route, sur la page Ulysse.
    </Card>
  </Step>
</Steps>

## Erreurs fréquentes

<AccordionGroup>
  <Accordion title="Mon compte Instagram n'est pas détecté">
    Le compte doit être **professionnel** (Business ou Créateur) et relié à une **Page Facebook** / un compte **Meta Business**. Un compte personnel ne peut pas être branché.
  </Accordion>

  <Accordion title="Les messages n'arrivent pas dans Océan">
    Vérifiez que l'**accès aux messages** est autorisé côté Instagram et que la connexion est active. Un premier message peut prendre quelques instants à remonter.
  </Accordion>

  <Accordion title="Un autre réseau ou canal ?">
    Voir le parcours unifié : [Ajouter un canal](/canaux/ajouter-un-canal). Pour WhatsApp, voir [Brancher WhatsApp](/canaux/whatsapp).
  </Accordion>
</AccordionGroup>
