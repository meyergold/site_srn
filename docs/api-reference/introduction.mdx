<p class="srn-eyebrow">API</p>

L'API Sairen expose en **REST** ce que la plateforme fait au quotidien : déclencher des **appels sortants**, envoyer et recevoir des **SMS**, **joindre un contact** sur le bon canal et **piloter vos agents**. Requêtes et réponses en **JSON**, authentification par clé.

## Les bases

  <Card title="Production" icon="server">

  </Card>
  <Card title="Staging" icon="flask">

</CardGroup>

## Authentification

Chaque requête porte votre clé dans l'en-tête **`x-api-key`**.

```bash
curl https://api.sairen.io/agents \
  -H "x-api-key: VOTRE_CLE_API"
```

<Warning>
  Gardez votre clé **côté serveur**. Ne l'exposez jamais dans un front public ni dans un dépôt.
</Warning>

## Les familles d'endpoints

<CardGroup cols={2}>
  <Card title="Leads — appels sortants" icon="phone-arrow-up-right">
    Déclencher un appel téléphonique et suivre son statut.

    `POST /leads/v3/phone-call` · `GET /leads/v3/phone-call/status` _(v2 disponible)_
  </Card>

  <Card title="Contact — SMS & messages" icon="comment-sms">
    Envoyer un SMS, relire l'historique d'un contact, recevoir les SMS entrants.

    `POST /api/contact/send-sms` · `GET /api/contact/{contact_id}/{channel}`
  </Card>

  <Card title="Reach — joindre un contact" icon="paper-plane">
    Atteindre un contact sur un canal — **Talk**, **Send** ou **Chat**.

    `POST /v3/reach`
  </Card>

  <Card title="Agents" icon="robot">
    Lister vos agents et récupérer leurs variables dynamiques _(v3 / beta)_.

    `GET /agents` · `GET /agents/v3`
  </Card>

  <Card title="Config" icon="gear">
    Configuration persistante par client (webhook, token), par agent.

    `POST /config/setup` · `GET·PUT·DELETE /config/setup/{agent_id}`
  </Card>
</CardGroup>

## Réponses & erreurs

Les endpoints renvoient du **JSON** et suivent les **codes HTTP standards** : `2xx` en cas de succès, `4xx` pour une requête invalide ou une clé manquante, `5xx` côté serveur. Le détail de chaque schéma se trouve sur la page de l'endpoint concerné.

<Note>
  Dépliez la section **Endpoints** dans le menu de gauche pour tester chaque route directement, avec vos propres valeurs.
</Note>
