Vos groupes de labels sont prêts, mais rien ne se classe ? Il manque le nœud **Classifier une tâche** dans votre workflow : c'est lui qui déclenche la classification.

## À quoi sert ce nœud

Le nœud de classification demande à l'IA de lire l'échange traité par le workflow et de poser les bons labels des groupes que vous avez sélectionnés. Placez-le après le déclencheur, une fois que le contenu de l'échange est disponible — après une conversation créée, un message reçu ou un appel terminé.

Dans la palette **Actions**, l'étape à choisir est **Classifier une conversation** : elle lit l'échange et attache les labels à la conversation.

Le canal n'a pas d'importance : tout déclencheur de workflow peut mener à une classification.

## Ajouter le nœud

<Steps>
  <Step title="Placez le nœud dans le workflow">
    Depuis la palette **Actions**, insérez l'étape de classification après le déclencheur. Dans l'exemple ci-dessous, elle s'intercale entre la récupération des messages et une condition qui décide de créer une tâche.

    <Frame caption="Le nœud de classification, entre le déclencheur et la suite du workflow.">
      <img src="/images/rainbow/classifier-une-tache-1.png" alt="Nœud de classification dans un workflow Rainbow" />
    </Frame>
  </Step>

  <Step title="Nommez le nœud">
    Donnez-lui un nom qui dit ce qu'il fait — « Classifier par motif » plutôt que « Action 2 ». C'est ce nom qui s'affiche sur le canvas.
  </Step>

  <Step title="Rédigez la consigne du nœud">
    Le champ **Prompt** porte la consigne générale : comment lire l'échange et comment trancher. Une consigne par défaut est déjà en place — elle demande à l'IA de choisir les valeurs les plus pertinentes en se basant uniquement sur le contenu de l'échange, et de laisser vide si rien ne correspond.

    <Frame caption="La configuration du nœud : consigne générale, puis groupes de labels.">
      <img src="/images/rainbow/classifier-une-tache-2.png" alt="Panneau de configuration du nœud de classification" />
    </Frame>
  </Step>

  <Step title="Sélectionnez les groupes de labels">
    Ce champ est **obligatoire** : choisissez au moins un groupe. Chaque groupe ajouté affiche son nombre de labels et son propre champ de description — c'est là que vous précisez, pour ce groupe seulement, comment choisir entre ses labels.
  </Step>
</Steps>

<Info>
  **Deux niveaux de consigne, et ils se complètent.** La consigne du **nœud** vaut pour toute la classification. La description de chaque **groupe** précise comment arbitrer entre les labels de ce groupe. Écrivez le général dans le nœud, le particulier dans le groupe.
</Info>

<Tip>
  L'interrupteur **Continuer si erreur** décide de la suite si la classification échoue : activé, le workflow poursuit ses étapes ; désactivé, il s'arrête là. Activez-le quand la classification est un enrichissement, laissez-le désactivé quand la suite n'a aucun sens sans elle.
</Tip>
