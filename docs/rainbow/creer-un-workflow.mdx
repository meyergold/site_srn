Vous voulez qu'une règle métier s'exécute toute seule — sans y penser, sans oubli ? C'est exactement ce que fait un workflow Rainbow. Voici comment créer le vôtre.

## Ce qu'est un workflow

Un workflow enchaîne des étapes à partir d'un **déclencheur** : une conversation qui arrive, un appel qui se termine, un label qui est posé… À chaque fois que l'événement se produit, Sairen déroule vos étapes : envoyer un message, créer une tâche, classer l'échange, mettre à jour un contact, lancer un appel IA.

Les e-mails ne font pas exception : ils arrivent dans Océan comme des conversations, donc les mêmes déclencheurs s'appliquent.

La palette de gauche regroupe tout ce que vous pouvez ajouter : **déclencheurs**, **actions**, **logique** (les conditions), **attentes** et **boucles**.

## Créer votre premier workflow

<Steps>
  <Step title="Ouvrez Rainbow et créez un workflow">
    Depuis Rainbow, cliquez sur **Créer un workflow** et donnez-lui un nom parlant — vous le retrouverez dans la liste.
  </Step>

  <Step title="Choisissez le déclencheur">
    Sélectionnez l'événement qui lance le workflow. C'est le point de départ de tout le reste :

    | Déclencheur | Se produit quand |
    | --- | --- |
    | **Conversation créée** | Un nouvel échange arrive, quel que soit le canal |
    | **Message reçu** | Un message entre dans une conversation existante |
    | **Label appliqué** | Un label est posé — vous pouvez viser **un label précis** |
    | **Appel terminé** | Un appel se termine, transcription disponible |
    | **Session IA démarrée / terminée** | Un agent IA prend ou rend la main |
    | **Message reçu par l'IA** | L'agent IA reçoit un message |

    <div style={{position: 'relative', width: '100%', margin: '12px 0'}}>
      <video src="/images/rainbow/creer-un-workflow-2.mp4" poster="/images/rainbow/creer-un-workflow-2.png" autoPlay muted loop playsInline controls style={{width: '100%', borderRadius: '16px', border: '1px solid rgba(120, 110, 255, 0.25)', display: 'block'}} />
    </div>

    Deux filtres optionnels resserrent le déclenchement : le **type de canal** (WhatsApp, SMS, RCS…) et une **connexion précise** (un numéro WhatsApp en particulier, par exemple). Sans filtre, le workflow réagit à tous.
  </Step>

  <Step title="Ajoutez vos étapes">
    Enchaînez les actions dans l'ordre voulu depuis la palette de gauche. Par exemple : **Classifier une tâche** pour poser vos labels, puis **Envoyer un message** pour accuser réception.

    Les étapes **Logique** ouvrent deux branches selon une condition, les étapes **Attente** patientent jusqu'à une réponse ou l'expiration d'un délai.
  </Step>

  <Step title="Testez, puis activez">
    Vérifiez le comportement sur un cas réel, puis activez le workflow. Il s'exécute désormais à chaque déclenchement.
  </Step>
</Steps>

<Tip>
  Commencez par un workflow court — un déclencheur, deux étapes. Vous l'enrichirez une fois le comportement validé.
</Tip>

## Bon à savoir

<AccordionGroup>
  <Accordion title="Un workflow peut-il faire appel à l'IA ?">
    Oui, de deux façons : une étape **Classifier une tâche** pose automatiquement vos labels, et un [agent IA](/produit/rainbow-agents) peut prendre la main quand il faut de la souplesse. Le déterministe pour la fiabilité, l'IA pour les cas nuancés.
  </Accordion>

  <Accordion title="Combien de workflows puis-je créer ?">
    Autant que nécessaire. Préférez plusieurs workflows courts et lisibles à un seul workflow qui fait tout.
  </Accordion>
</AccordionGroup>
