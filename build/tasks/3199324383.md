# [Tool Transfer Call] Retour d'état après transfert

- **Priorité** : Élevée
- **Source** : Support team & QA
- **Item Monday** : https://sairen-company.monday.com/boards/5103238969/pulses/3199324383

## Description

Le tool Transfer Call ne renvoie aucun retour d'état à l'agent : il est impossible de savoir si le transfert a abouti ou échoué. Attendu : un retour explicite, succès ou échec, avec la raison de l'échec quand elle est connue (numéro injoignable, canal non téléphonique, timeout). Vu sur SIMAGO, appel du 2 septembre 13h30 : le tool a répondu « Le transfert n'est disponible que pour les appels téléphoniques » alors qu'il s'agissait bien d'un appel téléphonique.

## Critères d'acceptation

_à compléter avec le produit si absents ci-dessus._
